Transcribing American Sign Language into English with Deep Learning

An end-to-end pipeline that converts ASL video clips into English text using body keypoint extraction, a Transformer encoder, and CTC sequence decoding — trained on 30,000 real signing clips from the How2Sign dataset.

+ CTC as primary loss (70/30) Best 0.7497
+ T5-base correction (flan-t5-base) 0.7597

The critical unlock was fixing a training/evaluation mismatch: the model was optimising 70% attention-decoder loss while being evaluated on CTC output. Flipping the ratio (70% CTC, 30% attention) dropped CER from 0.85 → 0.75 in a single training run.

How It Works
ASL video clip
   └─► OpenPose / MediaPipe  → 201-dim keypoints per frame
         └─► Conv1D subsampler  → local feature mixing
               └─► Transformer encoder  4 layers · d=256 · 5.5M params
                     └─► CTC beam search  → English text output
